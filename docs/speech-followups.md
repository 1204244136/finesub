## 二、各批「不要做什么」（摘要，展开在维护者的本地计划里）

动手前先读对应那条——每一条都是量过之后关掉的，不是没想到：

- **P10 分离器分块权重改三角权重**——已撤回，`demix.py` 早就是 Hamming 窗 + counter 归一。
- **不把 Silero 提升为基础检测器**——外部横向证据只有一个 60 s 片段。
- **不抄 legacy env 别名机制**——不刻意兼容的规则限于 1.0.0 前的开发中版本。
- **不向 Whisper 主解码器注入术语**（`initial_prompt` / `hotwords`，owner 判定）——那个 prompt 面装不下
  有意义的术语量，而且会改变解码行为（见 [`asr-align.md`](asr-align.md)「根因：前文污染下的窗内崩塌，不是语言检测漂移」）。
  术语只经 `--asr-context` 进第二模型。
- **不拿外部 DER 数字当目标**——素材难度分布不同，我们的说话人线不用 DER。
- **不凭机器参考的 CER 给 ASR 底座定级**（2026-09-07 反馈包复核）——那份包只做了结构检查：没有人工逐字稿，
  两份输出互比的距离当不了噪声底，VAD 与分离的影响又混在里面。真要做底座选型，前置条件是人工逐字稿、同设备
  同精度、统一输入（都分离或都不分离）、配对差值的置信区间，并控制分句粒度（按时长把文本分进窗口时，每四段
  合并一次 CER 就涨约 0.17）。只在真有选型决策时立项。
- **不往 CT2 加 CUDA graph capture**——KV cache 每步增长，要先做 shape-stable 重写（上千行
  C++），且它攻击的是组批已经在攻击的那个瓶颈。
- **分离器 FP8 / 手写 GEMM / 真 batch / 换 checkpoint / TensorRT / 16 kHz 分离**——
  [`separator-optimization.md`](separator-optimization.md) 的 E12/E14/E16 各自给了上限或硬否决。
- **三条已核实关闭的疑虑**——dry-run 与 `--execute` 复用同一段代码、`cli/_vendor` 不被 git
  跟踪、以及标点后处理是**减法且幂等**、不是恢复式标点。

- **自带时间戳与说话人的外部模型：两件可做、都没接线**（2026-09-26 评估，四家：Azure MAI-Transcribe-2「mai2」、
  `gemini-3.5-transcribe`「35t」、MOSS 开源版与 MOSS Pro；读数在维护者的本地评估报告里）。结论是**没有一家能整体替代
  生产链路**：mai2 词尾系统性偏早、不标重叠、切窗后分人断裂；35t 只有短语起点更准，其余各维不如生产、配额与稳定性差；
  MOSS 只给段级时间、人多或长上下文时并人，Pro 会静默漏段，开源版要 WSL 里的推理服务、与「生产不起子进程」相冲。
  值得做的两件都只换一维：
  - **文字：生产分句 + mai2 文字替换。** 切点与时间不动，行内文字换成 mai2 的：6 集里 5 集 CER 比生产低约 2 个点
    （相对约 −20%，少的是汉字错字），换进生产行后逐行 CER 仍低 0.015。代价是云端依赖、约 $0.10/h。
  - **说话人：少人的整集用 MOSS Pro 单趟。** 观测到 ≤5 人、≤46 min 的 4 集 B³ 0.96–1.00，两个声学参照 0.73–0.94。
    按参照估人数、≤4 人才用 Pro、说话时长覆盖不足就回退。⚠ 样本是同一档节目、每格 1 次；闸门不是逐集无损，覆盖率也抓不到
    「覆盖完整但并人」——接入前要在别的节目上冻结规则再验。这项长处属于 MOSS 底座：开源版整集单趟读数相同，Pro 多的是稳定。
    生产在这几集上输在精度（声音相近的几个人并进一条轨，即多人串轨），不是拆人。⚠ **在另一档节目上没有复现**（2026-10-04，
    开源 MOSS 整集单趟，姐姐咚咚 8 集）：去掉被服务配置截断的结尾后与生产打平、编辑代价更贵——那档节目上生产本来就没有串轨。
    所以它是串轨文件上的候选修法，不是「少人就用它」；要先能按文件认出串轨。
  - **重叠处按人分别转写（没列进两件可做，因为日语没测）。** MOSS 的不同说话人段可以互相重叠、各带各的字，重叠段文字召回
    所有臂里最高；生产只有一路 Whisper，重叠处另一人的话只能丢。只在中文远场会议上测过（那批数据在 MOSS 的评测集里），
    要先有日语带文字的重叠真值。
