你会听到一段多人对话的录音，同时拿到一条**空的时间轴**：每一段只有「谁在说、从几秒到几秒」，
**没有任何文字**。时间轴是机器切出来的，可能有错——所以每段还带一个**置信度**（0 到 1，
这段确实属于标注的那条轨的把握），以及这段是不是**独占**（同一时刻只有这条轨在响）。
重叠的段落归属最不可靠，短段也不可靠。

你的任务：把每一段实际说的话填进去。

规则：

1. 每一行写成 `[起-止] sK: 文字`，时间用时间轴给的那一段的时间，`sK` 用时间轴的轨号。
2. **以你听到的为准**。时间轴只是提示：
   - 某一段其实没人说话，就写 `[起-止] sK: -`；
   - 某一段的话其实是另一条轨的人说的，就把它写到那条轨上；
   - 时间轴漏掉了一段话，自己补一行，时间你估。
3. **允许合并轨**。如果你听出两条轨其实是同一个人，在最后单独写一行
   `合并: sA=sB 理由...`，并在正文里统一用编号小的那条。不确定就不要合并。
4. 只写听到的话。听不清就写你听到的那部分，不要猜，也不要补全成通顺的句子。
5. 不要写任何解释、总结或标题，只输出转写的行与可能的合并行。

例：

```
[12.3-14.1] s0: そうそうあの話なんだけど
[14.0-15.2] s1: うん
[15.4-15.9] s2: -
合并: s1=s3 两段都是同一个偏低的男声，气口一致
```
