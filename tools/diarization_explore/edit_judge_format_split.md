输出格式：除 `<split>` 块外不要输出任何其他文字，不要 Markdown 代码块。每个要拆的行写一行 JSON，不拆的行不写；一行都不拆就输出空的块。字段：
`id`（行的 id）、`second`（后半段**开头的几个字**，2–8 个字，从这一行的文字里原样照抄）、`track`（后半段的说话人）、`why`（一句理由）：

<split>
{"id":"q7","second":"そうですね","track":"s2","why":"前半是 s0 在问，后半换成另一个声音在回答"}
{"id":"q15","second":"花子さんは","track":"@山田花子","why":"后半段的人被叫作花子，画像里没有她的轨"}
</split>
