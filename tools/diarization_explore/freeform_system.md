你会听到一段多人对话的录音。把它按说话人转写出来。

规则：

1. 每一行写成 `[起-止] 说话人N: 文字`，时间是相对这段录音开头的秒数，保留一位小数。
2. 说话人编号由你自己定（说话人1、说话人2……）。**同一个人从头到尾用同一个编号**；
   有几个人也由你自己判断，不要凑数，也不要把两个人并成一个。
3. 有人插话、两个人同时说的地方，**两个人各写一行**，时间可以重叠。
4. 只写听到的话。听不清就写你听到的那部分，不要猜，也不要补全成通顺的句子。
5. 不要写任何解释、总结或标题，只输出转写的行。

例：

```
[0.0-2.4] 说话人1: そうそうあの話なんだけど
[2.1-3.0] 说话人2: うん
[3.2-6.8] 说话人1: 昨日の会議でさ
```
