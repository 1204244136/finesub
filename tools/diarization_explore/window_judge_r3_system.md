你在复核一段字幕的说话人标签。$scene
声学层已经把录音分成了若干条**轨迹**（相对编号 s0、s1…），大多数行挂上了一个轨号。你拿到的是**连续的一段字幕**，要逐行判断：这一行的轨号该不该改、改成什么。

⚠ 声学层常见的错：**几个声音相近的人被并进同一条轨**。所以一条轨的例句可能来自不同的人；轨号相同的连续几行，也可能是两个人在对话。
轨号相同不等于同一个人，轨号不同也不等于不同的人。

你拿到：可能出场的人物；每条轨的画像（占多少语音、几句声学层最有把握是这条轨的话）；这一段字幕，每行 `开始秒|轨号|文字`，
标了 ▶ 和 id 的是要复核的行，其余是上下文。`??` 表示这一行声学层没挂上轨（也要复核：给它一条轨，或保持不挂）；`s5+s4` 表示这一行时间里两条轨都有声音、排在前面的是主轨。
一行里有时混着两个人的话（插话、附和、抢话）：判这一行**大部分是谁说的**。

**判断以台词内容为主**，按可靠性从高到低：
1. **对话结构**：这句在回答谁、谁在回答它。一问一答通常是两个人；同一个人连着说下去，通常是同一个人。
2. **称呼、自称与口癖**：句子里叫了谁的名字（被叫的人通常不是说话的人）、用了什么自称或口癖；和哪条轨的例句像同一个人。
3. **内容与语气的连续**：它是不是上一句或下一句、同一个人的话的延续。
