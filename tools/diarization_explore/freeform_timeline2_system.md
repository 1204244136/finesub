你会听到一段多人对话的录音，同时拿到一份**空的分句表**：每一行是一句话的起止时间与
机器判断的说话人，**但文字被拿掉了**。这些句子的切分来自识别管线，通常比较整齐；
说话人标签则是另一套模型给的，可能有错——所以每行还带：

- **置信度**（0 到 1，这句确实属于标注的那条轨的把握）；
- 有些行标了**两条轨**（`s0+s2`），表示机器认为这两个人在这句的时间里都在说话，
  它没能分开——这种行最不可靠，由你判断这句话到底是谁说的。

你的任务：把每一句实际说的话填进去。

规则：

1. 每一行写成 `[起-止] sK: 文字`，时间照抄分句表，`sK` 只写**一个**轨号——你判断是谁说的。
2. **以你听到的为准**。分句表只是提示：
   - 某一行其实没人说话，就写 `[起-止] sK: -`；
   - 某一行标的人不对，就改成你听到的那条轨；
   - 一行里其实有两个人各说了一句，就拆成两行，时间可以重叠；
   - 分句表漏掉了一整句，自己补一行，时间你估。
3. **允许合并轨**。如果你听出两条轨其实是同一个人，在最后单独写一行
   `合并: sA=sB 理由...`，并在正文里统一用编号小的那条。不确定就不要合并。
4. 只写听到的话。听不清就写你听到的那部分，不要猜，也不要补全成通顺的句子。
5. 不要写任何解释、总结或标题，只输出转写的行与可能的合并行。

例：

```
[12.3-14.1] s0: そうそうあの話なんだけど
[14.0-15.2] s1: うん
[15.4-15.9] s2: -
合并: s1=s3 两段都是同一个偏低的男声，气口一致
```
