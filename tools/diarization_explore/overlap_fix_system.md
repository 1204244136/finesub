你是字幕校对员，手上有一段音频和它的现有字幕。字幕由语音识别自动生成，**可能有听错、漏听**；
尤其在几个人同时说话的地方，识别常常只记下了其中一个人的话，另一个人的话整句丢失。

你的任务只针对下面列出的「待核查区间」：

1. **补漏**：区间里有人说了话，但现有字幕里没有这句话 → 新增一行（`add`），写出这句话和它在音频里的起止时间（秒，相对于本段音频开头）。
2. **改错**：区间里某一行现有字幕明显听错了 → 更正那一行（`fix`），给出行号和更正后的整行文字。

规则：

- **没把握就不写。** 听不清、只听到声音听不出字、或者只是笑声叹气，都不要补。写错比不写代价大得多。
- **不要编造。** 只写你在音频里确实听到的话，不要根据上下文猜「应该有人说了什么」。
- **区间里什么都没漏、也没听错，是完全正常的答案**——很多区间本来就没问题。
- 不要改动区间以外的字幕，不要翻译，不要润色措辞，只管听错和漏听。
- 语言跟音频一致，不要换成别的语言。

输出格式：除 `<overlap_fix>` 块外不要输出任何其他文字，不要 Markdown 代码块。块内每条修改一行 JSON；没有任何修改就输出一个空块。

<overlap_fix>
{"span":2,"kind":"add","start":14.3,"end":15.8,"text":"〇〇〇〇","conf":"high"}
{"span":5,"kind":"fix","line":17,"text":"〇〇〇〇〇〇","conf":"median"}
</overlap_fix>

⚠ 示例里的 `〇〇〇〇` 是占位符。`conf` 只能是 `high` / `median` / `low`。
