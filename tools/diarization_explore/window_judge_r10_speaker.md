$scene
除了纠错和翻译，你还要在 `<translated>` 每个 `sub` 行的 `spk` 列写出这一行是谁说的。声学层已经把录音分成了若干条**轨迹**（相对编号 s0、s1…），`<asr_result>` 的 `spk` 列是它给每个源段挂上的轨号：`??` 表示这一段声学层没挂上轨（也要复核：给它一条轨，或保持不挂）；`s5+s4` 表示这段时间里两条轨都有声音，排在前面的是主轨。user 消息的 `<speaker_tracks>` 块给出可能出场的人物和每条轨的画像（占多少语音、几句声学层最有把握是这条轨的话）$audio_inventory。

⚠ 声学层常见的错：**几个声音相近的人被并进同一条轨**。所以一条轨的例句可能来自不同的人；轨号相同的连续几行，也可能是两个人在对话。
轨号相同不等于同一个人，轨号不同也不等于不同的人。
一行里有时混着两个人的话（插话、附和、抢话）：判这一行**大部分是谁说的**。

**判断以台词内容为主**，按可靠性从高到低：
1. **对话结构**：这句在回答谁、谁在回答它。一问一答通常是两个人；同一个人连着说下去，通常是同一个人。
2. **称呼、自称与口癖**：句子里叫了谁的名字（被叫的人通常不是说话的人）、用了什么自称或口癖；和哪条轨的例句像同一个人。
3. **内容与语气的连续**：它是不是上一句或下一句、同一个人的话的延续。
$audio
声学层的轨号多数时候是对的，只有看出明确的理由才改。

`spk` 列只能写下面几种之一：
- 照抄输入里这一行的 `spk`：现在的轨号是对的（`??` 照抄是保持不挂轨；`s5+s4` 照抄原样或只写主轨 `s5` 都行，都是说主轨 s5 对）。证据不足时也照抄——改错比不改贵；
- 另一条轨号：画像里列出的任意一条轨——如果画像里有一条轨就是这一行的说话人，用它；
- `@新轨`：**新建一条轨**。只在你判断这一行的说话人**不是**画像里任何一条轨的人时用。写法是 `@` 加一个标签：认得出是出场人物里的谁，就写他的名字（照抄「可能出场的人物」里括号前的写法）；认不出，就写 `@甲`、`@乙` 这样的代号。同一个标签就是同一条新轨，本窗口里这个人的其他行也用同一个标签。

合并行写这一行那个人的轨号。并进来的源段主轨相同，就照抄；主轨不同时，先确认它们是同一个人说的（合并规则里「换人说话绝不合并」说的人，用你在这里的判断），再写那个人的轨号。
`spk_note` 列：`spk` 的主轨和输入的主轨不同时（包括改成 `@新轨`、给 `??` 挂上轨、合并行里主轨不同的源段），写一句理由；照抄的行留空。

例（只看 `spk` 与 `spk_note` 两列）：
- 输入 `s0`、延续了自己上一句的话题 → `spk` 写 `s0`，`spk_note` 留空；
- 输入 `s0`、在回答上一句对她的称呼，自称与 s2 的例句一致 → `s2`，「在回答上一句对她的称呼，自称与 s2 的例句一致」；
- 被叫作花子的人在回答，画像里没有一条轨是她 → `@山田花子`，「被叫作花子的人在回答，画像里没有一条轨是她」；
- 和上一行对话的另一个人，画像里没有他的轨，认不出是谁 → `@甲`，「和上一行对话的另一个人，画像里没有他的轨，认不出是谁」。

`</translated>` 之后、`<next_advice>` 之前，输出有且仅有一个 `<tracks>` 块：`sub` 行的 `spk` 里出现的每条轨（`s5+s4` 按主轨 s5 算，`??` 不写）和每个新标签各写一行 `轨号或标签 = 人名`，说它是谁；人名照抄「可能出场的人物」里括号前的写法，认不出写 `不明`。例：
<tracks>
s2 = 佐藤一郎
@山田花子 = 山田花子
@甲 = 不明
</tracks>
