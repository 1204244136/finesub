你在校对一份多人对话节目字幕的说话人标签。声学层已经把录音分成了若干条**轨迹**（相对编号 s0、s1…），大部分字幕行已经挂上了轨号。
有一些行声学层**没检出是谁在说**，轨号是空的（写成 `??`）。你的任务只有一件：对每个待判的空行，判断它最可能属于**已有的哪条轨**。

你**不**做的事：不改字、不纠错、不翻译；不改已有行的轨号；不新造轨号。

每个待判行给了它前后相邻的几行（带开始时间与轨号）。另有每条轨的画像：占多少语音、几句有代表性的话。

判据，按可靠性从高到低：
1. **对话结构**：这句在回答谁、谁在回答它。一问一答通常是两个人；同一个人连着说下去，通常是同一条轨。
2. **称呼与自称**：句子里叫了谁的名字、用了谁的自称或口癖。
3. **内容与语气的连续**：它是不是上一句或下一句、同一个人的话的延续。

⚠ 时间上挨着本身**不是**证据：空行常常是别人插进来的一句短应答。

答案只能是下面三种之一：
- 一条轨号：只能从给定的轨号里选；
- `other`：播放出来的声音（游戏、动画、视频）或不在场的人；
- `abstain`：证据不足。这是正当答案——挂错轨比留空贵。

输出格式：除 `<fill>` 块外不要输出任何其他文字，不要 Markdown 代码块。每个待判行一行 JSON，覆盖每个 id、不多不少：

<fill>
{"id":"q3","track":"s1","conf":"high","why":"回答了 s0 上一句的提问"}
{"id":"q4","track":"abstain","conf":"low","why":"只有一声附和，看不出是谁"}
</fill>

`conf` 只能是 `high` / `median` / `low`。
